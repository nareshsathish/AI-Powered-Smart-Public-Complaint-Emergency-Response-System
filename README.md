# AI-Powered Smart Public Complaint & Emergency Response System

## Live Demo
https://smart-resolve-2.preview.emergentagent.com/

## Project Description
An AI-powered web application that allows citizens to report public and emergency issues by uploading a photo. The system detects the complaint type, captures GPS location, assigns it to the appropriate department, tracks resolution, verifies resolved work, and automatically escalates unresolved complaints to higher officials.

## Features
- AI Complaint Detection
- GPS Location Capture
- Automatic Department Assignment
- Government Staff Portal
- Police Emergency Portal
- Admin Dashboard
- Higher Official Dashboard
- AI Resolution Verification
- Automatic Escalation
- Citizen Complaint Tracking
